# Data product verification template

Candidate provider roles from the project brief are planning inputs, not verified integrations.

| Provider | Candidate use | Exact product ID | Status |
| --- | --- | --- | --- |
| NASA | SST history/baseline, precipitation, optional ocean color | To verify | Not integrated |
| Copernicus Marine | Ocean physics and optional biogeochemistry | To verify | Not integrated |
| Open-Meteo | Weather and selected marine forecasts | To verify | Not integrated |

For **each** selected product, record: URL, version, licence/attribution, API/authentication, variable and standard name, unit, depth, native grid, coverage, temporal cadence, latency, quality flags, missing-data semantics, selected role, fallback policy, and date verified. Test access and data quality at the chosen region before declaring integration complete.

Open-Meteo marine outputs may derive from Copernicus; trace this before using both in one assessment.
